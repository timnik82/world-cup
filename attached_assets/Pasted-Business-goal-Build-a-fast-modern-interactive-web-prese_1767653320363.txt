Business goal:
Build a fast, modern, interactive web-presentation (mini-app) about FIFA World Cup history (1930–present). It must feel like an application: each slide is a React screen with interactive elements.

Tech stack (must use):
Vite + React + TypeScript + Tailwind CSS + Reveal.js (integrated inside React) + Motion (Framer/Motion) for animations.
Add: TanStack Query (React Query) for on-demand API calls, Zustand for global state, Zod for validating local JSON data.

MVP scope (6 slides) — build THIS first:
1) Intro slide:
   - “Random fact” button (uses local facts data)
   - “Add to favorites” button
2) Timeline slide:
   - year slider (1930..latest in local data)
   - card updates when year changes (host, champion, runner-up, final score)
3) Matches slide:
   - filters (tournament year + stage)
   - table/list of matches from local JSON
   - “Show details” button per match that opens a modal
4) Match details modal:
   - On-demand API call ONLY when user clicks “Load details”
   - Use TanStack Query with enabled:false and refetch() on click
   - Provide a mock provider by default (reads local mock JSON), and leave a clean API adapter to later plug real providers (football-data.org / TheSportsDB).
5) Records slide:
   - local recompute button (no network)
   - show a couple of computed stats from local data (e.g., total goals per tournament or top scoring matches from local dataset)
6) Final/Favorites slide:
   - list favorites (facts + matches)
   - allow removing favorites

Data rules:
- Base data must live locally in /data as JSON: tournaments.json, matches.json, facts.json (you can generate small sample data for now).
- Do NOT scrape the web. No invented facts: if something is missing, show “unknown”.
- Add Zod schemas for these JSON files.

Performance rules:
- Initialize Reveal.js deck only once (avoid double-init on React re-renders).
- Lazy-load heavy slides and only activate expensive logic when the slide is active (Reveal slidechanged).
- Keep the initial load fast.

Design:
- Clean, modern, readable typography; Tailwind.
- Add subtle micro-interactions and animations with Motion.
- Make it responsive (desktop-first, but should still work on mobile).

Deliverables:
- A working Vite project with clear folder structure:
  src/deck/ (Reveal wrapper), src/slides/, src/components/, src/data/, src/lib/api/, src/store/
- README with: install, dev, build, and how to switch API provider (mock vs real via env).
- Add .env.example (no secrets committed).

Development flow:
1) First, output a short implementation plan and file structure.
2) Then start building the MVP described above.
3) After finishing, run/verify the app and fix obvious errors.
